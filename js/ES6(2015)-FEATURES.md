# 🚀 ES6 (ECMAScript 2015) – Key Features

## 1. let & const

- Block-scoped variables that replace `var` and prevent common scope bugs.

## 2. Arrow Functions (=>)

- Shorter function syntax with lexical `this` binding.

## 3. Template Literals (` `)

- Allows string interpolation and multi-line strings using backticks.

## 4. Destructuring

- Extract values from arrays or objects into variables easily.

## 5. Default Parameters

- Function parameters can have default values.

## 6. Rest Operator (...)

- Collects multiple arguments into a single array.

## 7. Spread Operator (...)

- Expands arrays or objects for copying or merging (immutability).

## 8. Enhanced Object Literals

- Cleaner object syntax with shorthand properties and methods.

## 9. Classes

- Syntactic sugar over prototypes for object-oriented programming.

## 10. Modules (import / export)

- Enables modular, reusable, and maintainable code structure.

## 11. Promises

- Handles asynchronous operations more cleanly than callbacks.

## 12. for...of Loop

- Iterates over iterable values like arrays and strings.

## 13. Map

- Key-value collection with better performance and key flexibility.

## 14. Set

- Stores unique values and removes duplicates automatically.

## 15. Symbols

- Creates unique and non-colliding object keys.

## 16. Object.assign()

- Copies properties from source objects into a target object.

---

### 🎯 One-line Summary

ES6 modernized JavaScript with better syntax, scoping, async handling, and modularity, making code cleaner and more maintainable.
